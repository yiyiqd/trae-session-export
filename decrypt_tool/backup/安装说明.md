# trae-db-decrypt 备份 & 换电脑安装说明

备份时间：2026-08-24
来源：https://github.com/Oh-My-Trae/trae-db-decrypt （master）
附加：适配 TRAE SOLO CN 的 `scan_solo.py` 和 `刷新密钥并解密.bat`（已放入 src/）

## 备份内容

```
backup\
├─ trae-db-decrypt-master.zip          # 完整仓库压缩包（单文件备份）
└─ trae-db-decrypt-master\             # 解压后的源码
   ├─ src\scan_memory.py               # 内存扫描提取密钥
   ├─ src\decrypt_db.py                # 页面级 AES 解密
   ├─ src\scan_solo.py                 # ★ 适配 TRAE SOLO CN 的扫描器
   ├─ src\刷新密钥并解密.bat            # ★ 一键提取密钥+解密
   ├─ src\token_report.py              # token 统计（帖子原功能）
   └─ docs\                            # 原理文档（含 article_solo.md）
```

## 换电脑后安装步骤

1. 安装 **Python 3.10+**（勾选 Add to PATH）。
2. 安装依赖：`pip install pycryptodome`
3. **确保 Trae 正在运行**（密钥在进程内存里，不运行扫不到）。
4. 按你的 Trae 版本核对 `src\scan_solo.py` 顶部两个常量：
   - `PROCESS_NAME`：TRAE SOLO CN 用 `TRAE SOLO CN.exe`；Trae CN 用 `Trae CN.exe`
   - `DB_PATH`：`%APPDATA%\<Trae目录>\ModularData\ai-agent\database.db`
5. 双击 `src\刷新密钥并解密.bat`：
   - 先扫内存提取密钥（生成 `decrypted_key.json`）
   - 再解密出 `database_decrypted.db`
6. 用标准 sqlite 打开 `database_decrypted.db`，查
   `chat_session`（中文标题）、`chat_message`（对话内容）等表。

## 重要提示

- **密钥不跨机器**：`decrypted_key.json` 只对当前这台机器的数据库有效。
  换电脑后必须重新运行扫描（步骤 5），不要带旧 key 文件。
- **数据库路径/进程名**可能因 Trae 版本（CN / SOLO CN / 国际版）不同而变化，
  以本机 `%APPDATA%` 下实际目录为准。
- 解密是**页面级 AES-256-CBC**（SQLCipher 4：PBKDF2-HMAC-SHA512、256000 迭代），
  只解密主文件页面，不含 WAL 里的最新未落盘数据；如需最新数据，先正常关闭 Trae 再解密。
